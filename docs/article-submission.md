# 提供素材的方式

直接貼 YouTube 影片網址即可。若已有逐字稿、文章、HTML 檔案或整理頁，也可以直接交付；不需要先自己寫完文章，不必填 JSON 或後台表單。

收到影片後，代理先取得人工或自動字幕；沒有字幕時，再使用已安裝的本機轉錄工具。只有實際無法取得內容時，才回報原因與最少需要補充的素材，不拿標題或影片簡介假裝讀過全文。

文章會包含：

- 想解決的問題、方法的核心觀點與適用情境。
- 步驟一、步驟二等具體動作，每步搭配例子與完成判準。
- 流程圖、排程或可直接使用的練習模板。
- 編輯心得、教學或生活應用，以及常見誤區。
- 原影片連結、可核對的時間碼與取材範圍。

影片原述、編輯補充與心得分開標示；不捏造親身試用、研究結果、成功率或時間碼。完整逐字稿只作為編輯素材，正式文章採原創改述與可執行的練習設計。

所有文章沿用方法練習室的米白、墨綠與暖橘版型。完成內容與瀏覽器驗證後，依當次及既有發布授權上稿並讀回正式站。
