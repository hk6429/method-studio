# 文章圖卡規範

依使用者 2026-10-18 指示，新文章與既有文章重畫一律沿用 picture3 教育資訊圖風格。

- 每篇各製作一張橫式 16:9 與一張手機 5:8 圖卡，兩版依內容獨立排版。
- 使用 picture3 完整風格：米白底、多色 pastel 模組、深藍標題、繁體中文台灣用語、細線外框與小型大乃公仔。依文章關係選流程、比較、概念圖或其他合適構圖。
- 使用內建 image_gen，每張依文章內容生成；原圖與 prompt 留在 scratch，成品以 WebP 轉檔。
- 每張公開與下載成品嚴格小於 **1,000,000 bytes**，壓縮後檢查中文字與箭頭清晰度。原始 PNG 可另外保留於 scratch，不冒稱它也符合成品大小限制。
- 公開尺寸目前為橫式 1600×900、手機 1000×1600；不以裁切橫圖代替手機設計。
- `overview.image` 與 `cardImage` 使用橫式成品；`mobileImage` 使用直式成品。設定 `kind: infographic` 與四個尺寸欄位 `width`、`height`、`mobileWidth`、`mobileHeight`。
- 頁面使用 picture/source：600 CSS 像素以下選手機圖，其餘選橫式圖。實測 currentSrc、自然尺寸、無水平溢出，確認裝置切換有效。
- 新圖直接取代文章概覽圖與原本簡易流程圖；既有排程表、正文、來源、文章與步驟 ID、收藏及進度保持完整。
- 圖中文字必須忠於文章，保留來源與編輯補充界線，不額外加入成效、安全、健康或排名保證。
- 生成、尺寸／大小檢查與目視核對皆通過，才可將新圖加入文章目錄並發布。尚未生圖時不得放假路徑、換色 SVG 或宣稱已完成。

驗證時先做受影響的契約測試、validate/build，再檢查桌面與真正手機視窗。發布沿用本次／既有授權；只發布 dist，並讀回正式資產與文章。
